Variable LMS · Product dossier · Reviewed 17 September 2026

One application, clear boundaries.

A .NET 10 LTS modular monolith with React + Vite and PostgreSQL, released as versioned OCI images.

Derived documentation

This summary is not an implementation specification. Canonical repository sources govern: ADR log · Modules · Distribution and recovery · Invariants. Application implementation has not started.

Structure

Business capabilities own their state.

Identity & Organization, Licensing, Course Authoring, Enrollment & Cohorts, Assessment, Progress & Certification, Discussion and Notifications have explicit public interfaces and private implementations. Only owning modules mutate state.

Deliberate read-only relational joins and local transactions are allowed. No module-to-module HTTP, database-per-module mandate or speculative broker is introduced. Extraction later requires real scaling, reliability or ownership need and an explicit consistency redesign.

Integrity

Make important outcomes durable.

Identity and isolation

One organization per initial installation; organization ownership and parent/run consistency on records. Opaque revocable cookie sessions use PostgreSQL initially. RLS is not mandatory.

Transactions and retries

Required audit, state and work intent commit together. Workers lease persisted work and retry. Business uniqueness prevents duplicate runs/certificates; email is not promised exactly once.

Migration safety

The deployment package invokes migrations with separate DDL credentials. The web runtime has restricted rights and checks schema compatibility; a lock alone does not make live upgrades safe.

Release and restore

Immutable release tags/digests, compatible versioned packages, release notes, supported upgrade paths and backups of database, files, license/configuration and keys. Customer chooses upgrade timing.

ADR review

Every proposal was reviewed independently.

ADR-1 is superseded. ADR-4 and ADR-8 are accepted. ADR-2, 3, 5, 6, 7, 9, 10, 11 and 12 are accepted with modification. New ADR-13 establishes atomic state and durable effects.

Modified decisions remove mandatory Redis/RLS, automatic web-startup DDL, blanket join bans, assumed NativeAOT and automatic SaaS capability. No whole existing ADR remains Proposed; unsupported future clauses are explicitly deferred rather than accepted by association.

Packaging

Deployment topology is independent.

Small deployments use a versioned Compose package. A supported Kubernetes path uses versioned Helm packaging. Future extracted services add independently versioned images to the package. Neither OCI delivery nor Helm implies a SaaS product.

Redis and object storage require actual need. The conventional managed .NET runtime is the baseline. The separate Variable issuer signs versioned licenses; the LMS validates them offline without implementing billing or mandatory telemetry.
