Variable LMS · Product dossier · Reviewed 18 September 2026

Learning, in your environment.

Variable LMS is a product of Variable, initially serving s2c’s internal training. Organizations run cohort-based training in infrastructure they control.

Derived documentation

This summary is not an implementation specification. Canonical repository sources govern: Vision · Accepted decisions · MVP. The identity foundation is implemented; learning features remain planned. See the current implementation and local setup.

The product

Courses become guided learning.

Authors publish text-based courses. Authorized staff schedule cohorts and assign Learners. Facilitators support discussion; Learners read required content, complete graded assessments and earn a course certificate.

One account, explicit roles

Learner, Course Author, Cohort Coordinator, Learning Facilitator, Administrator and Organization Manager can be combined as a role set. Resource grants define course/cohort authority.

Each enrollment is a learning run

Progress, attempts and completion belong to the run. Re-enrollment starts fresh and preserves earlier history.

Precise learner capacity

One unique active account with Learner entitlement consumes one seat. Pending, inactive and staff-only accounts consume none.

Stable course credentials

Automatic issuance remains once per user/course, even if the learner later completes another run. The fixed PDF uses snapshotted display data.

Distribution

Customer-controlled releases.

Variable publishes versioned OCI images and deployment packages. Customers pull and apply releases on their own schedule, without requiring interactive vendor access. Compose supports a small installation; Helm is the intended Kubernetes packaging path when supported.

The same images can serve on-premises, private cloud, assisted operation and future vendor hosting. Hosted tenancy and billing are separate future decisions.

Status

Ready for foundational implementation.

The September baseline settles the architecture, authorization, licensing and learning-record identity. Feature-local questions remain explicit. No application is implemented yet and no production capacity is claimed.
