# MVP — Minimum Viable Product

> **Status:** Not Yet Defined  
> **Last Updated:** June 2026

---

## Purpose

This document will define the Minimum Viable Product (MVP) for the LMS — the smallest set of features that delivers value to users and validates the product direction.

---

## MVP Definition

> **Not yet defined.** The MVP will be specified once core features are documented and prioritized.

### Likely MVP candidates

Based on initial brainstorming, the MVP may include:

- [ ] User registration and authentication
- [ ] Course creation (basic)
- [ ] Course browsing and enrollment
- [ ] Lesson delivery (text/video content)
- [ ] Basic progress tracking
- [ ] Role-based access (Learner, Instructor, Admin)

### Likely NOT in MVP

- Assessments and grading
- Certificate generation
- Organization management
- Advanced analytics
- Payment processing
- Social features (discussions, reviews)
- SCORM/xAPI support

---

## MVP Success Criteria

> **TBD** — How will we know the MVP is successful?

Potential criteria:

- A learner can sign up, find a course, and complete it
- An instructor can create a course with lessons and publish it
- An admin can manage users and courses
- Progress is tracked and visible
