# Deferred entity: Media Asset

> **Status:** Deferred\
> **Authority:** Supporting — future scope only\
> **Updated:** 2026-09-17

## Purpose

Record that a generalized upload catalog is not needed for the current MVP. Forums and lessons have no file/image uploads. Organization logos and certificate render artifacts are owned by their existing domains and use controlled storage keys; they do not require a generic Media Asset domain now.

When an actual media-upload feature is approved, define organization ownership, authorized uploader, object key, type/size validation, access, lifecycle and cleanup in its feature design. Do not create speculative asset tables or a video pipeline.

## Open questions

None that block MVP; any later media requirements need their own scope decision.
