# Data Model

> **Last Updated:** June 2026

---

## Purpose

This folder contains conceptual entity definitions for the LMS. These are **not** database schemas or ORM models — they are planning documents that describe what data the system needs to manage.

Actual database design will happen during the implementation phase, informed by these documents.

---

## How to Add an Entity

1. Copy `entity-template.md` to a new file with a descriptive name (e.g., `course.md`)
2. Fill in the template sections
3. Use `TBD` for sections that are not yet defined
4. Add the entity to the index below
5. Cross-link to related features and other entities
