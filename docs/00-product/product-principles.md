# Product principles

> **Status:** Confirmed baseline\
> **Authority:** Canonical — product guidance\
> **Updated:** 2026-09-17

## Purpose

Guide choices within the accepted Variable LMS scope.

- Keep product truth near its implementation and tests; resolve semantics before encoding them.
- Start with useful cohort-based learning and add scope only for a demonstrated need.
- Make learner state and staff actions understandable: show permissions, progress and failure recovery clearly.
- Preserve learning evidence and credential meaning. Derived summaries must not overwrite history.
- Respect customer ownership of infrastructure, data and upgrade timing.
- Build keyboard access, semantic UI and clear error states from the first slice. A formal conformance/release target remains [Q41](open-questions.md#q41).
- Minimize collected personal data and define retention/erasure before handling production records; do not claim a compliance certification from technical controls alone.
- Prefer reversible engineering choices, but record deliberate product changes and their consequences.
